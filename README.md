# RnxCAD

Настольный 2D CAD-редактор для Windows с русскоязычным интерфейсом. При запуске открывается редактируемый план павильона. Для чистого чертежа нажмите `Ctrl+N`.

## Запуск

Готовая сборка находится в `dist/RnxCAD.exe`. Для неё нужен установленный .NET Desktop Runtime 10 x64.

При наличии .NET 10 SDK можно запустить проект из исходников или собрать exe заново.

```powershell
dotnet run --project RnxCAD.csproj
dotnet publish RnxCAD.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o dist
```

## Работа с чертежом

- **Построение.** Используйте панель инструментов или командную строку (`Ctrl+L`). Доступны отрезок, полилиния, прямоугольник, круг, дуга через три точки, линейный размер и однострочный текст.
- **Точный ввод.** Команда `L`, точка `0,0`, затем `@1000,0` построят отрезок длиной 1 000 единиц. Поддерживаются абсолютные точки `1200,800`, относительные `@500,0`, полярные `@500<45` и дробные координаты `12,5;8,2`.
- **Выбор и правка.** Выбирайте объекты щелчком или рамкой. Рамка слева направо выбирает объекты целиком, справа налево захватывает пересечённые. `Shift` добавляет к выделению. Доступны перенос, копирование, удаление и отмена действий.
- **Слои.** Щёлкните по имени, чтобы сделать слой активным. Меняйте видимость, блокировку, цвет и толщину линий. В панели свойств можно посмотреть параметры выбранного объекта и перенести его на другой слой.
- **Навигация.** Колесо масштабирует вокруг указателя. Средняя кнопка мыши перемещает вид. `Home` показывает весь чертёж, `F3` переключает привязки к концам, серединам и центрам, `F7` — сетку, `F8` — ортогональный режим. `F1` открывает справку.

## Файлы

`Ctrl+S` сохраняет оригинал в `.rnxcad`, включая редактируемые размеры и свойства слоёв. `Ctrl+O` открывает `.rnxcad` или текстовый `.dxf`. Кнопка **Экспорт** создаёт `.dxf` или векторное изображение `.svg`.

DXF поддерживает плоские `LINE`, `LWPOLYLINE`, `POLYLINE`, `CIRCLE`, `ARC` и базовые `TEXT`. При импорте редактор сообщает о пропущенных записях. При экспорте в DXF размеры превращаются в линии и надписи. DWG, 3D, блоки, штриховки и листы в этой версии недоступны.
